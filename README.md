
# 📚 BookNest - Online Book Borrowing Platform

## 🌐 Live URL

👉 https://book-borrow-delta.vercel.app

---

## 🎯 Purpose

BookNest is a modern web application that allows users to explore, search, and borrow books online. It aims to digitize the traditional library system with a clean UI and secure authentication.

---

## 🚀 Key Features

* 🔐 User Authentication (Login, Registration, Google Login)
* 📱 Fully Responsive Design (Mobile, Tablet, Desktop)
* 📚 Browse All Books with Search Functionality
* 🏷️ Category Filter (Story, Tech, Science)
* 🔍 Book Details Page (Private Route)
* 📖 Borrow Book Feature with confirmation message
* 👤 User Profile with Update Option
* 🎞️ Animated UI using Animate.css
* 📢 Marquee for New Arrivals
